LinkedList.add_first = O(1) - appends something to the front of the linked list which will only change the head and the head's link

LinkedList.add_last = O(1) - appends something to the back of the linked list which will only change the tail and the tail's link

LinkedList.remove_first = O(1) - removes the head 

Stack.push = O(1) - uses LinkedList.add_first

Stack.pop = O(1) - uses LinkedList.remove_first

OrderQueue.enqueue = O(1) - uses LinkedList.add_last 

OrderQueue.dequeue = O(1) - uses LinkedList.remove_first

Store.find_product = O(n) - this function will go through the list of products to find the product

Store.find_customer = O(n) - this function will go through the list of customers to find the customer

Store.find_order = O(n) - this function will go through the list of orders to find the order
